# Development

## Local install

From the repository root:

```bash
./scripts/install-local.sh
```

Then open Cinnamon **System Settings → Desklets** and add **SpeedPup**.

## Remove local development copy

```bash
./scripts/uninstall-local.sh
```

## Cinnamon Spices submission

The submit-ready source tree is:

```text
speedpup@taskpuppynatani/
```

A real `screenshot.png` should be added to that directory only after the UI
is ready to show publicly.
